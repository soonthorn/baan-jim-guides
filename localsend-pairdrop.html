ส่งภาพข้ามแพลตฟอร์ม
ด้วย LocalSend และ PairDrop

ถ่ายภาพด้วย iPhone แต่ต้องนำไปใช้บนคอมพิวเตอร์ Windows หรืออยากส่งภาพจาก Android ให้คนใช้ Mac การส่งข้ามระบบไม่จำเป็นต้องต่อสายหรือส่งผ่านแชตเสมอไป

LocalSend และ PairDrop เป็นเครื่องมือฟรีที่ช่วยส่งภาพและไฟล์ระหว่างอุปกรณ์ต่างระบบ โดยเลือกใช้ได้ตามสถานการณ์: LocalSend เหมาะกับอุปกรณ์ที่ใช้ประจำ ส่วน PairDrop สะดวกเมื่อต้องการเปิดเว็บแล้วส่งทันที

เลือกตัวไหนดี?

เรื่องที่เปรียบเทียบLocalSend — วิธีใช้ผ่านแอปPairDrop — วิธีใช้ผ่านเว็บ
การเตรียมติดตั้งแอปบนทั้งสองเครื่องเปิดเว็บไซต์บนทั้งสองเครื่อง
บัญชีผู้ใช้ไม่ต้องสมัครไม่ต้องสมัคร
เครือข่ายอยู่ในเครือข่ายภายในเดียวกันใช้เครือข่ายเดียวกัน หรือจับคู่เพื่อส่งข้ามเครือข่าย
อินเทอร์เน็ตไม่จำเป็นระหว่างส่งผ่านเครือข่ายภายในควรมีเพื่อเปิดเว็บและเชื่อมต่อบริการ
เหมาะกับส่งภาพระหว่างเครื่องของตัวเองเป็นประจำส่งภาพเป็นครั้งคราว หรือไม่สะดวกติดตั้งแอป

LocalSend รองรับ Windows, macOS, Linux, Android และ iOS ส่วน PairDrop ใช้งานผ่านเว็บเบราว์เซอร์สมัยใหม่ได้หลายระบบ

วิธีที่ 1: ส่งภาพด้วย LocalSend

เตรียมก่อนส่ง

  1. ดาวน์โหลดจาก เว็บไซต์ LocalSend และติดตั้งบนทั้งสองเครื่อง
  2. เชื่อมต่ออุปกรณ์เข้ากับเครือข่ายเดียวกัน เช่น Wi-Fi ของบ้าน
  3. เปิดแอป LocalSend บนทั้งสองเครื่อง

ไม่จำเป็นต้องมีอินเทอร์เน็ตออกภายนอก ขอให้ทั้งสองเครื่องสื่อสารกันผ่านเครือข่ายภายในได้ การส่งไฟล์ไม่ต้องผ่านบริการฝากไฟล์บนคลาวด์

ขั้นตอนส่งภาพ

  1. ที่เครื่องต้นทาง เปิดหน้าส่ง แล้วเลือกภาพหรือไฟล์ที่ต้องการ
  2. เลือกชื่ออุปกรณ์ปลายทางที่ปรากฏ
  3. ที่เครื่องปลายทาง ตรวจชื่อผู้ส่งและกดยอมรับ
  4. รอจนส่งเสร็จ แล้วเปิดตรวจไฟล์ที่ได้รับ

หากหาไฟล์ไม่เจอ ให้ตรวจโฟลเดอร์รับไฟล์ในการตั้งค่าของแอป อย่าเพิ่งสรุปว่าภาพจะเข้าแอปรูปภาพโดยอัตโนมัติ

ข้อดีและข้อจำกัด

  • ข้อดี: เหมาะกับการส่งซ้ำระหว่างมือถือและคอมพิวเตอร์ของตัวเอง และใช้งานได้แม้อินเทอร์เน็ตบ้านขัดข้อง
  • ข้อจำกัด: ต้องเตรียมแอป และเครือข่ายต้องอนุญาตให้อุปกรณ์มองเห็นกัน ความเร็วขึ้นอยู่กับ Wi-Fi และอุปกรณ์ที่ใช้

วิธีที่ 2: ส่งภาพด้วย PairDrop

ขั้นตอนส่งภาพในเครือข่ายเดียวกัน

  1. เปิด pairdrop.net บนทั้งสองเครื่อง
  2. สำหรับเริ่มต้น ให้ทั้งสองเครื่องใช้ Wi-Fi เดียวกัน
  3. ตรวจชื่อของแต่ละเครื่องที่แสดงบนหน้าเว็บ
  4. ที่เครื่องต้นทาง แตะหรือคลิกอุปกรณ์ปลายทาง แล้วเลือกภาพ
  5. ที่เครื่องปลายทาง กดยอมรับและรอรับไฟล์ให้ครบ
  6. ดาวน์โหลดหรือบันทึกภาพตามตัวเลือกที่เบราว์เซอร์แสดง

บนมือถืออาจมีตัวเลือกบันทึกภาพหรือแชร์ต่อ ส่วนคอมพิวเตอร์ให้ตรวจรายการดาวน์โหลด หากรับหลายไฟล์พร้อมกัน อาจได้รับเป็นไฟล์ ZIP ซึ่งต้องแตกไฟล์ก่อนใช้งาน

ถ้าอยู่คนละ Wi-Fi ใช้ได้ไหม?

PairDrop รองรับการส่งข้ามเครือข่าย โดยใช้การจับคู่อุปกรณ์ด้วยรหัสหรือ QR Code หรือเข้าห้องชั่วคราวเดียวกัน แล้วจึงเลือกเครื่องปลายทางเพื่อส่งไฟล์

ทั้งสองฝ่ายต้องออนไลน์และเปิดหน้าเว็บไว้ระหว่างส่ง วิธีนี้ไม่ใช่การฝากไฟล์ไว้ให้ผู้รับมาโหลดภายหลัง

ข้อดีและข้อจำกัด

  • ข้อดี: เริ่มใช้งานได้ผ่านเว็บ ไม่ต้องติดตั้งแอป และมีทางเลือกสำหรับส่งระหว่างคนละเครือข่าย
  • ข้อจำกัด: ขึ้นอยู่กับเบราว์เซอร์ เครือข่าย และความพร้อมของบริการ ควรเปิดหน้าเว็บค้างไว้จนส่งเสร็จ

ส่งแล้วภาพจะชัดเท่าเดิมไหม?

ควรเลือกส่ง ไฟล์ภาพต้นฉบับ แทนการแคปหน้าจอหรือดาวน์โหลดภาพที่ถูกย่อมาแล้ว เพราะเครื่องมือส่งไฟล์ไม่สามารถกู้รายละเอียดที่หายไปก่อนหน้านั้นได้

อีกเรื่องที่ต้องแยกกันคือ “ส่งไฟล์สำเร็จ” กับ “เปิดไฟล์ได้” เช่น ภาพชนิด HEIC อาจต้องใช้โปรแกรมที่รองรับบนเครื่องปลายทาง หากต้องนำไปใช้กับหลายโปรแกรม การแปลงสำเนาเป็น JPEG อาจสะดวกกว่า โดยเก็บต้นฉบับไว้ด้วย

หากหาอีกเครื่องไม่เจอ หรือส่งไม่สำเร็จ

ลองตรวจตามลำดับนี้:

  1. ตรวจเครือข่าย — สำหรับ LocalSend ให้ทั้งสองเครื่องอยู่ในเครือข่ายภายในเดียวกัน ส่วน PairDrop ลองใช้การจับคู่หรือห้องชั่วคราว
  2. เปิดแอปหรือหน้าเว็บไว้ทั้งสองเครื่อง — ระหว่างลองส่ง อย่าเพิ่งล็อกหน้าจอหรือสลับออกจากแอป
  3. ตรวจสิทธิ์เข้าถึง — อนุญาตการเข้าถึงภาพ ไฟล์ หรือเครือข่ายภายในตามที่ระบบร้องขอ
  4. ตรวจ Wi-Fi แบบผู้เยี่ยมชม — บางเครือข่ายแยกอุปกรณ์ออกจากกัน แม้จะเชื่อม Wi-Fi ชื่อเดียวกัน
  5. ลองส่งภาพเดียวก่อน — หากสำเร็จแล้วจึงส่งหลายภาพหรือไฟล์ขนาดใหญ่
  6. ตรวจพื้นที่ว่างและตำแหน่งบันทึก — บางครั้งรับไฟล์แล้ว แต่ไฟล์อยู่ใน Downloads หรือแอป Files

หากใช้ VPN หรือเครือข่ายขององค์กร การตั้งค่าเครือข่ายอาจมีผลต่อการค้นหาและเชื่อมต่ออุปกรณ์

ข้อควรระวังก่อนส่ง

  • ตรวจชื่อเครื่องปลายทางทุกครั้ง โดยเฉพาะเมื่อใช้ Wi-Fi ร่วมกับผู้อื่น
  • ไม่รับไฟล์จากอุปกรณ์ที่ไม่รู้จัก
  • ไม่เผยแพร่รหัสจับคู่หรือรหัสห้องชั่วคราวให้คนที่ไม่เกี่ยวข้อง
  • ตรวจว่ารับภาพครบและเปิดได้ ก่อนลบต้นฉบับ
LocalSend ส่งผ่านเครือข่ายภายในและเข้ารหัสการรับส่ง ส่วน PairDrop ใช้ WebRTC ซึ่งเข้ารหัสระหว่างส่ง แต่การเชื่อมต่อบางกรณีอาจผ่านเซิร์ฟเวอร์ตัวกลาง จึงไม่ควรเข้าใจว่า PairDrop ส่งตรงระหว่างเครื่องโดยไม่ผ่านเซิร์ฟเวอร์ในทุกสถานการณ์

เลือกใช้ในชีวิตประจำวัน

  • ส่งภาพจากมือถือเข้าคอมพิวเตอร์ที่บ้านบ่อย ๆ: เริ่มจาก LocalSend
  • ส่งภาพให้เพื่อนโดยไม่อยากติดตั้งแอป: เปิด PairDrop
  • อยู่คนละสถานที่: ใช้การจับคู่หรือห้องชั่วคราวของ PairDrop และเปิดเว็บไว้ทั้งสองฝ่ายจนรับเสร็จ

แหล่งข้อมูล

  • เว็บไซต์ LocalSend ภาษาไทย
  • PairDrop — คุณสมบัติและวิธีเชื่อมต่อ
  • PairDrop — คำถามที่พบบ่อย
