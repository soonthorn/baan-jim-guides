MakHam Voice Studio

พิมพ์ข้อความ เลือกเสียงผู้หญิงหรือผู้ชาย แล้วสร้างไฟล์เสียง WAV สำหรับเล่านิทานหรืออ่านบทความได้จากหน้าต่างเดียว

ดาวน์โหลดโปรแกรม (.zip)ดูวิธีติดตั้ง

โปรแกรมนี้ใช้ PyThaiTTS และโมเดล MakHamTTS ของ PyThaiNLP ทำงานบนเครื่อง Windows หลังดาวน์โหลดโมเดลครั้งแรกแล้วใช้งานออฟไลน์ได้

ลองฟังเสียงก่อน

ทั้งสองเสียงอ่านข้อความเดียวกันจากนิทานปลาทอด ความเร็วปกติและไม่มีการปรับทุ้ม–แหลม

เสียงผู้หญิง

newvoice_female

ตัวอย่างช่วงเปิดเรื่องและบทพูดสั้น ๆ

เสียงผู้ชาย

newvoice_male

ตัวอย่างข้อความเดียวกันเพื่อเทียบเสียง

ติดตั้งบน Windows

  1. ติดตั้ง Python 3.11 แบบ 64 บิตดาวน์โหลดจาก python.org แล้วเลือก “Add python.exe to PATH” ระหว่างติดตั้ง
  2. ดาวน์โหลดและแตกไฟล์โปรแกรมกดปุ่มดาวน์โหลดด้านบน แตกไฟล์ ZIP ลงในโฟลเดอร์ที่ต้องการเก็บโปรแกรม เช่น Documents\MakHamVoiceApp
  3. ติดตั้งไลบรารีเปิด PowerShell ในโฟลเดอร์ที่มี app.py แล้วรันคำสั่งต่อไปนี้:
    python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install --upgrade pip
& .\.venv\Scripts\python.exe -m pip install pythaitts==1.0.0 librosa==0.11.0
    หากคำสั่ง python ไม่พบ ให้ลอง py -3.11 -m venv .venv ในบรรทัดแรก
  4. เปิดโปรแกรมดับเบิลคลิก run.cmd ครั้งแรกที่สร้างเสียง โปรแกรมจะดาวน์โหลดโมเดลและข้อมูลเสียงผู้พูดจาก PyThaiNLP อัตโนมัติ
ต้องใช้อินเทอร์เน็ตสำหรับการติดตั้งและดาวน์โหลดเสียงครั้งแรก เตรียมพื้นที่ว่างอย่างน้อย 1 GB ไฟล์โมเดลหลักและเสียงผู้พูดสองเสียงรวมประมาณ 327 MB

วิธีสร้างไฟล์เสียง

  1. ใส่ข้อความพิมพ์หรือวางข้อความในแท็บ “ข้อความ” หรือกด “เปิดไฟล์ .txt” เพื่อโหลดไฟล์ UTF-8
  2. เลือกเสียงและตั้งค่าเปิดแท็บ “ตั้งค่าเสียง” เลือกผู้หญิงหรือผู้ชาย แล้วปรับค่าตามต้องการ
  3. เลือกที่บันทึกระบุชื่อไฟล์ WAV และกด “สร้างไฟล์เสียง” ข้อความยาวจะถูกแบ่งเป็นช่วงแล้วรวมเป็นไฟล์เดียว
  4. ฟังในโปรแกรมเมื่อเสร็จ กด “▶ ฟังเสียง” เพื่อฟังทันที หรือ “■ หยุด” เพื่อหยุดเล่น

ตั้งค่าอะไรได้บ้าง

เสียงnewvoice_female หรือ newvoice_male
ความเร็ว1.0× คือปกติ ค่าน้อยลงพูดช้า ค่ามากขึ้นพูดเร็ว
ทุ้ม / แหลมปรับระดับเสียงหลังสังเคราะห์ ค่า 0 คือเสียงเดิม การปรับมากอาจฟังไม่เป็นธรรมชาติ
ความดัง1.0× คือเดิม การเพิ่มมากอาจทำให้เสียงแตก
พักระหว่างช่วงค่าเริ่มต้น 0.25 วินาที ขึ้นบรรทัดใหม่ในข้อความเพื่อกำหนดจังหวะพักเอง

เมื่อมีปัญหา

เปิดโปรแกรมแล้วแจ้งว่าไม่พบ Python

ตรวจว่าแตก ZIP แล้ว และติดตั้ง Python กับไลบรารีในโฟลเดอร์เดียวกับ app.py โดยใช้คำสั่งในขั้นตอนติดตั้ง

ดาวน์โหลดโมเดลไม่สำเร็จ

ตรวจอินเทอร์เน็ตแล้วลองสร้างเสียงอีกครั้ง ไฟล์โมเดลจะอยู่ในโฟลเดอร์ hf-cache ข้างโปรแกรม

ข้อความยาวแล้วสร้างเสียงไม่ได้

แบ่งข้อความเป็นประโยคสั้น ๆ โดยขึ้นบรรทัดใหม่ที่จังหวะหยุดตามธรรมชาติ แล้วลองอีกครั้ง

หน้าต่างเล็กจนไม่เห็นการตั้งค่า

ใช้แท็บ “ตั้งค่าเสียง” และเลื่อนภายในแท็บ ปุ่มสร้างเสียงและฟังเสียงจะอยู่ด้านล่างของหน้าต่าง
